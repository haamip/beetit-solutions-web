Use the secure client workflow

Identity documents and permanent deletions require extra care.

Identity status

Upload link expires after seven days. Identity files remain client-level.

Delete client
Permanent deletion removes the client record and secure client files. The admin requires the client name, the word DELETE and a final confirmation.
010203
01
Email ID upload linkSends the client a secure one-use upload link rather than asking them to send ID through ordinary email.

Verify ID and DOBOnce received, check the document and confirm the date of birth in the client record.

Permanent deletionUse only when the whole client record genuinely needs to be removed. This cannot be undone.
Rule of thumb:
If you are unsure whether something should be deleted, leave it in place and contact HAKT instead.

9. Simple routine

The easiest way to manage DPP

A short day-to-day checklist for normal administration.

DPP Legal Solutions Admin Guide
Open Dashboard

Check today's bookings, upcoming appointments, new enquiries and notifications.

Review Bookings

Confirm, reschedule or cancel only after checking the appointment and contact details.

Check Enquiries

Mark genuine messages read, then link new work to the correct client and MAT file.

Search Clients before creating

Keep one person as one client record. Create new matters underneath them.

File notes and documents correctly

Choose the right MAT matter before adding internal notes or client documents.

Use secure ID workflows

Request ID through the one-use upload link and verify it in the client record.

Use Help when unsure

Search the built-in guides, open this PDF or raise a HAKT support request.

Automatic things you do not need to do manually

Booking confirmations, cancellations and reschedules can email the client automatically through the booking workflow. The system also checks for duplicate clients before linking new work.

Website changes

Use Website only for approved permanent public changes. Save and publish, then check the public site on desktop and mobile.
